Scenario authoring workspace

This workspace is intentionally static-safe. It gives non-developer contributors a starter template, plain-language validation, scaffold generation, and a JSON export path without adding any server dependency or direct model integration.

1. Choose a starter

Authoring pattern

  • Start from a proven scenario or the blank scaffold.
  • Edit plain-language fields, lists, and block text directly in the draft JSON.
  • Generate scaffolds when you need a fast starting point for blocks, rationale, rubric, or coaching.
  • Validate before downloading so schema problems are explained in plain language.
  • Keep the app static: scenarios live as local JSON files, not in a database or server.

Authoring checklist

  • Keep ROLE, RULES, REFERENCE, DYNAMIC FACTS, TASK, OUTPUT, and CHECKS visibly distinct.
  • Make strongest-practice sections, precedence, output, and handling explicit.
  • Add at least one plausible-but-weaker counterfactual for compare-and-contrast training.
  • Write coaching in plain language so learners understand why the stronger structure wins.
  • Keep scenarios completable in 5–10 minutes.
