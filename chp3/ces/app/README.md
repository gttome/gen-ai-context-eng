# Context Envelope Studio

Version: v1.7.0
Build ID: ces-v1.7.0-innovation-labs

Context Envelope Studio is a static, mobile-first Chapter 3 learning application for shaping high-quality context envelopes. Learners place authored cards into ROLE, RULES, REFERENCE, DYNAMIC FACTS, TASK, OUTPUT, and CHECKS; compare the package against strongest practice; run the envelope in an external LLM; and review the result inside the app.

## What this build adds

- **Counterfactual Studio MVP**: review now compares your current envelope, strongest practice, and a plausible-but-weaker variant generated by the scenario engine
- **Adaptive Mission Director MVP**: the launch, rails, and summary screens now use local-only run history to recommend the next mission and weakest skill focus
- **Declarative scenario + coaching engine**: scenario packs now compile mission tags, authoring hints, and counterfactual variants through a front-end engine rather than scattered scenario-specific UI logic
- **Selector-layer refactor**: derived state now flows through `assets/js/state/selectors.js` so coaching, summary, comparison, and artifact generation read from a clearer shared view model
- authoring workspace upgrades for mission tags, counterfactual patterns, and engine preview
- refreshed documentation and test artifacts for the v1.6.1 build

- **Innovation Labs page**: a separate optional page (`innovation-labs.html`) now hosts 9 modular experimental features, each loaded from a registry so the core app can evolve without touching the labs runtime
- **3 education labs**: Teachable Doppelgänger, Productive Failure Time Machine, and Calibration Market
- **3 visual labs**: Claim-Evidence Constellation, Context MRI, and Session Hologram Replay
- **3 context-engineering labs**: Authority Firewall Simulator, Trajectory Auditor, and Prompt Card + Claim Ledger

## Run locally on Windows

1. Keep `start-server.bat` in the same folder as `index.html`.
2. Double-click `start-server.bat`.
3. Open `http://localhost:8000/` if the browser does not open automatically.

Do not use `file://` navigation for normal testing.

## Static hosting constraints

This app is designed for GitHub Pages or another static host.

Permanent non-goals:
- no direct LLM/API integration
- no accounts
- no server-side storage
- no remote analytics

## Key files

- `index.html` — main app
- `help.html` — learner-facing help
- `feedback.html` — local-only feedback capture
- `authoring.html` — static authoring workspace for scenario contributors
- `innovation-labs.html` — optional modular innovation feature hub
- `assets/data/scenarios/` — scenario JSON packs
- `assets/js/domain/scenario-engine.js` — declarative scenario/coaching compilation
- `assets/js/state/selectors.js` — shared derived-state / selector layer
- `assets/js/domain/mission-director.js` — local-only next-mission recommendation logic
- `assets/js/innovation-labs/` — isolated plug-in style feature modules and adapter
- `project-documents/` — continuation and QA documents
- `tests/` — validation and smoke-test scripts
