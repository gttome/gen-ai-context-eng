Help guide

Context Envelope Studio teaches Chapter 3 shaping discipline through short, artifact-producing runs. You are not writing a flashy prompt from scratch. You are turning already selected material into a legible operating package another person or run could review.

Core flow

  1. Choose a scenario pack and review the mission brief.
  2. Predict where the package could fail if shaped poorly.
  3. Place authored blocks into ROLE, RULES, REFERENCE, DYNAMIC FACTS, TASK, OUTPUT, and CHECKS by reasoning from purpose, trust, freshness, and reviewability.
  4. Set the precedence rule, output mode, and missing-information behavior.
  5. Copy the envelope into an external LLM and observe the result.
  6. Paste the observed output back into the app and review what the structure caused.
  7. Finish the run, compare with your prior attempt, and export a learner artifact if needed.

What changed in this iteration

  • Stage changes now return you to the top of the active workflow step instead of leaving you at the bottom of the page.
  • Coach this card now opens inline coaching on the selected card and keeps the next move visible.
  • The app now shows an always-visible Do this next coach strip near the top of the workflow so you Always know the next move.
  • Adaptive Mission Director now uses local-only progress to recommend the next scenario and skill focus.
  • Counterfactual Studio now compares your current envelope, strongest practice, and a plausible-but-weaker version so shaping consequences are visible.
  • Printable learner artifacts now open from a generated print view instead of an empty print window.
  • The authoring workspace now includes scaffold generators for starter blocks, rationale, rubric, coaching, mission tags, and counterfactual patterns.
  • Browser QA now includes stage-scroll checks, printable artifact checks, and a narrow-screen smoke flow.

Keyboard-only build path

  • Each unplaced block includes a destination dropdown, a Place button, and a Coach this card action that explains the shaping decision.
  • Each placed block includes Move up, Move down, and Move to section controls.
  • You never have to rely on drag-and-drop to finish the core activity.

Copy, compare, and print

  • The app includes a clipboard fallback for browsers that restrict navigator.clipboard.
  • After a completed run, the summary screen can compare the current attempt with the previous completed attempt for the same scenario.
  • You can copy or print a learner artifact for review, coaching, or class discussion.

Authoring workspace

The authoring workspace gives non-developer contributors a safe static pattern: choose a starter scenario, edit JSON transparently, generate missing scaffolds, validate against the scenario schema, preview the compiled scenario engine, and export a local JSON file for review.
