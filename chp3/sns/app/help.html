How to use Signal-to-Noise Studio

This version adds mixed-signal paste-back review, clearer contradiction guidance, stronger replay comparisons, and the same support-page behavior across Help and Feedback.

Back to app Feedback

Core mission flow

  1. Choose a validation pack from the launch screen.
  2. Read the brief and capture a quick prediction about what feels important.
  3. Classify each card into Include, Summarize, Retrieve Later, or Omit.
  4. Watch the package preview, budget state, charts, and coaching update in real time.
  5. Build the package, move to the export screen, copy it into an external LLM, then paste the answer back into the in-app review box.
  6. Use the strongest-practice comparison and summary to understand what improved or weakened.

What the four actions mean

Include

Use this when the card materially changes the answer or required format and deserves direct space in the core package.

Summarize

Use this when the information matters but does not need full verbatim inclusion.

Retrieve Later

Use this for edge cases, follow-up detail, or conditional material that should stay accessible without crowding the package.

Omit

Use this when the card is stale, duplicated, background-heavy, or simply not worth the budget.

New iteration features

  • Glossary: Open the glossary from the metrics panel when you want Chapter 3 terminology visible.
  • Metric explainers: Use the “?” buttons beside each metric to understand what improves or weakens it.
  • Richer comparison reasoning: The comparison screen now explains why the stronger action is stronger for each mismatched card.
  • Paste-back review: After pasting an external model answer, inspect the rubric breakdown for structure, evidence coverage, grounding discipline, uncertainty handling, concision, and mixed-signal contradiction detection.
  • Bonus drills: Summary now offers more than one replay path so you can practice a tighter budget or an authority-vs-freshness challenge.

Where the paste-back step lives

It is not a separate app mode.

Paste-back lives on the Export screen after you press Build package → export workflow in the workspace.

  1. Classify every card in the workspace.
  2. Press Build package → export workflow.
  3. Use Copy package for external LLM.
  4. Run the package in another LLM window or tab.
  5. Paste the observed answer into Paste the external answer back here.

Touch and accessibility notes

  • Every primary card action has a button and does not require drag and drop.
  • The lane lists are easier to read on mobile in this version, so the recommended touch pattern is still tap-to-classify.
  • Use the step labels, charts, and coaching together. Charts are never the only explanation surface.
  • The app remembers your mission state locally so you can leave for the external LLM step and return without losing work.
