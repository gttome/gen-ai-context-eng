# Enterprise Readiness Navigator — Start Here

This ZIP is the continuation-ready handoff package for the current learner-focused build of **Enterprise Readiness Navigator**.

## Open the app
1. Place this folder anywhere on your Windows PC.
2. Double-click `start-server.bat`.
3. The browser should open automatically to the local app URL.

## Most important files
- `README.md` — quick orientation
- `START_NEW_CHAT_PROMPT.md` — paste this into a new chat to continue the project
- `index.html` — main app
- `help.html` — learner help page
- `feedback.html` — feedback page
- `project-documents/handoff.md` — current state and continuation guidance
- `project-documents/testing.md` — executed validation record
- `project-documents/architecture-and-file-map.md` — codebase structure
- `project-documents/setup-run-deploy.md` — local run and GitHub Pages notes

## Current app focus
This build is designed for learners. The core mission stays short and guided. Deeper support such as stakeholder reactions, replay story, coaching paths, advanced scenarios, and executive debriefing are available without turning the mission into extra work.
