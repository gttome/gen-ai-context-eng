# Enterprise Readiness Navigator

v0.3.1

A mobile-first learning app for practicing how an AI workflow moves from useful prototype to governed enterprise use.

What is inside:
- short scenario-based core missions
- optional advanced scenarios
- coaching styles that change support without adding extra required work
- stakeholder reactions and a decision-ready summary after the run
- replay support to help you see what changed across attempts

Run locally:
- place the folder anywhere on your Windows PC
- double-click `start-server.bat`
- your browser will open the app automatically

Main files:
- `index.html` — main application
- `help.html` — learner help page
- `feedback.html` — feedback page
- `project-documents/` — handoff and technical notes
