# Setup / Run / Deploy

## Local run
- Keep `start-server.bat` in the root next to `index.html`.
- Run `start-server.bat` on Windows.
- The local launcher behavior is preserved from the uploaded file.

## Static deployment
- Deploy the root folder contents to GitHub Pages or another static host.
- No backend or live API is required.

## Testing note
Deterministic module/render validation was completed in this environment. Browser automation against localhost was blocked by environment policy and is recorded in the test artifacts.
