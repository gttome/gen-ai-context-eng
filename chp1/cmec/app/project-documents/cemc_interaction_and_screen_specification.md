# Source Update — Interaction and Screen Specification

> Preserved filename; current meaning applies to CEMC.

## Interaction philosophy retained
The app behaves as a guided command center rather than a dense dashboard.

## Current screen hierarchy
- launcher
- mission brief
- package repair workspace
- live metrics sidebar
- compare workspace
- debrief
- Explore More
- Help
- Feedback

## Current mission flow
1. launch scenario
2. read brief
3. answer prediction
4. make guided changes
5. inspect compare/metrics/coaching
6. optionally run externally and paste back
7. complete debrief
8. replay or exit

## First-run support present
- plain-language help page
- scenario tags and why-it-matters notes
- recommended repair buttons
