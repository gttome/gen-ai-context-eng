Simple operating guide

Use the wizard from top to bottom.

The application is intentionally linear. Each step tells you what to do, why it matters, and what must be completed before the next step opens.

Choose mission Diagnose Build package Copy to ChatGPT Paste and review
Best first run

Do this in order

1
Pick Support Downgrade
This mission has the clearest teaching signal.
2
Choose the missing mechanism
Say what kind of context is missing before changing anything.
3
Select only the helpful items
Do not turn on everything. Keep the package focused.
4
Click one copy button
Use Copy everything to send to ChatGPT.
5
Paste only ChatGPT’s answer back
Then click Analyze pasted output.
6
Read the coaching
Look at the score, sentence feedback, and next best move.
What the app is teaching

Mechanism judgment

Grounding
Use source text, policies, or evidence the model cannot safely invent.
Memory
Carry forward prior facts, decisions, or open questions without pasting everything.
Dynamic facts
Inject current dates, status values, and account details the model cannot know on its own.
Mixed missions
Some missions need more than one mechanism at the same time.
External model step

Why copy / run / paste exists

No hidden automation: you can see the exact combined block before you run it. That keeps the learning transparent and keeps the site compatible with static hosting.
Good habit
Change one major variable at a time so the score movement stays interpretable.
Common mistake
Adding all available context instead of the right context.
