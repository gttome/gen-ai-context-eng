# Rubric Runner Lab

Rubric Runner Lab is a static HTML5 learning application that helps non-developer learners practice Chapter 2’s evaluation-and-iteration discipline.

## Current build
- Version: v1.5.1.0
- App type: static front-end app for Windows local use and GitHub Pages deployment
- Focus: evaluation-first learning, stronger onboarding, richer scoring coaching, a post-scoring best-practice review, scenario-specific coaching, two additional workplace scenarios, Chapter 2 teaching callouts, optional learning checks, and a learner-facing takeaway summary

## What this build includes
- walkthrough-first onboarding
- five pre-authored Chapter 2 scenarios
- score → best-practice review → diagnose → change → compare → decide workflow
- six live metrics
- help and feedback pages
- local persistence for theme, session state, feedback draft, and walkthrough visibility
- full `project-documents/` continuation set

## Run locally on Windows
1. Put the project in a normal local folder.
2. Double-click `start-server.bat`.
3. Open `http://localhost:8000/` if the browser does not open automatically.

## Deploy to GitHub Pages
1. Push the full folder contents to a GitHub repository.
2. Enable GitHub Pages for the repository root.
3. Wait for the site to publish.
4. Confirm that `index.html` is loading as the entry page.
