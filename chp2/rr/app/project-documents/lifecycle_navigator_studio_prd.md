# Lifecycle Navigator Studio PRD — Current Distillation

## Product requirement summary for this build
- preserve the short-session learning loop
- reduce cognitive load for average learners
- make the interface teach more directly during use
- keep the app static and continuation-friendly

## Current must-have features
- walkthrough-first onboarding
- guided scoring with richer help
- Chapter 2 explanatory callouts
- optional learning checks
- session takeaway summary


## v1.4 update
The current iteration adds a best-practice review step after baseline scoring submission. Learners score first, then the app surfaces only the biggest score gaps plus plain-language explanations before failure tagging begins.
