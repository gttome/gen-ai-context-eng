# Setup / Run / Deploy

## Windows local run
1. Put the project in a normal local folder.
2. Double-click `start-server.bat`.
3. Open `http://localhost:8000/` if the browser does not open automatically.

## GitHub Pages
1. Upload the full project contents to a repository.
2. Enable Pages from the repository root on the default branch.
3. Open the published URL and run a quick smoke test.

## Troubleshooting
- If Python is missing, install Python 3 and rerun `start-server.bat`.
- If localStorage seems stale during testing, clear site storage and refresh.
