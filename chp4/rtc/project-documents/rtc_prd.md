# RTC PRD

## Users
Knowledge workers who use generative AI in real work but do not need developer tooling.

## Core outcome
Complete one meaningful triage run in 5–10 minutes and leave with a credible triage record.

## Current product scope
- 5 guided scenarios
- fixed bottom coaching surface
- modal detail views for coach / impact / playbook
- replay analytics after completion
- exportable triage records
