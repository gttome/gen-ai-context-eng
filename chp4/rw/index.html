Available incidents

Use filters to choose a domain, difficulty, pack, or comparison mode. Then work one mission from incident review to debrief.

What you are practicing

  • Protect a known-good baseline before accepting a candidate change.
  • Use standing checks instead of intuition alone.
  • Spot what improved, what held, and what weakened.
  • Choose Release, Hold, or Iterate for a clear reason.
  • Close with monitoring follow-up, not false certainty.

How to get the most from a mission

  • Read the baseline before you read the candidate result.
  • Judge risky checks first so the important trade-offs stay visible.
  • Use the interpretation help when a check feels ambiguous.
  • Use the debrief to compare your path with the strongest-practice path.

Optional extension

Some missions include a manual external-model comparison step. That step is still part of the learning workflow because it lets you compare outside output against the same standing checks and release discipline.
