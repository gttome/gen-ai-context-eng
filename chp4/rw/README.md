# Regression Watchtower

A static HTML/CSS/JS learning application for Chapter 4 baseline protection, standing checks, release judgment, and monitoring follow-up.

- Build version: v15.0.0
- Delivery model: Windows local run + GitHub Pages static hosting
- Startup file: `start-server.bat`

## What changed in v15
- tuned small-screen readability with larger mobile typography and more generous spacing
- made the mission jump bar sticky on phones so section movement stays visible during long runs
- clarified the recommended mission order in the workspace
- reordered the packet on phones so baseline review appears before candidate review
- kept the app learner-first with no return of verification, replay, persistence, or export tooling

## Run locally
1. Place the project in a normal folder on Windows.
2. Double-click `start-server.bat`.
3. Open the printed localhost URL in a browser.

## Main learner flow
1. Choose a mission in the launcher.
2. Review the incident, proposed change, baseline, and candidate result.
3. Compare the standing checks.
4. Review current signals.
5. Choose a release judgment and monitoring follow-up.
6. Study the debrief.
