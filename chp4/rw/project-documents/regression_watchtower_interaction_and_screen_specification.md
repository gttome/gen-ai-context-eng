# Regression Watchtower Interaction and Screen Specification

## Launcher
- Presents the mission catalog with learner-facing filters.
- Shows the number of matching missions after filter changes.
 - Keeps the filter/result state readable for normal browser QA and small-screen use.

## Workspace
- Presents the incident, proposed change, candidate result, and baseline result.
- Shows standing checks with interpretation choices and instructional help.
- Shows current signals, release judgment, monitoring follow-up, and coaching sidebar.
 - Adds section-jump navigation for packet, checks, external step, signals, decision, and coaching.

## Debrief
- Summarizes decision alignment, check-level drift, strongest-practice reasoning, monitoring follow-up, and next-practice guidance.
