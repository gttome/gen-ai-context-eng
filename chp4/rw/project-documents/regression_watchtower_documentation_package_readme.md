# Regression Watchtower Documentation Package Readme

This package documents the current learner-first build of Regression Watchtower.

Version: v15.0.0

The implementation is a static educational application for Chapter 4 concepts: baseline protection, regression detection, release judgment, and monitoring follow-up.

This iteration adds:
- small-screen readability tuning
- sticky mission-jump navigation on phones
- clearer recommended mission-order guidance in the workspace
- mobile-first packet ordering that shows the baseline before the candidate result

The package remains learner-first and does not reintroduce verification workspace features, replay history, persistence, or export tooling.
