# QA Checklist

## Core learner flow
- Launcher loads and shows authored missions.
- Filters narrow the scenario list correctly.
- Starting a mission opens the workspace.
- Standing checks can be reviewed and scored.
- Release decision and monitoring follow-up can be selected.
- Completing the mission opens the debrief.

## Learning-quality checks
- Coaching text updates as the learner progresses.
- Interpretation help opens for each standing check.
- Debrief includes strongest-practice walkthrough and practice-next guidance.

## Shell and accessibility checks
- Theme toggle works and persists after refresh.
- Help and Feedback pages open and return cleanly.
- Workspace section-jump links move to the expected sections.
- Route changes move focus to the new screen heading.

## Build sanity checks
- Required app/docs/data files are present.
- No verification workspace, replay dashboard, persistence subsystem, or export tooling is present.
- Local HTTP checks return 200 for main pages and core assets.
