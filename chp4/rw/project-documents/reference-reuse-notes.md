# Reference Reuse Notes

## Reused conceptually
- comparison-first architecture discipline from the refined blueprint
- structured documentation package pattern from the example ZIP
- state/domain/ui separation for maintainability

## Intentionally not reused in v9
- verification workspace concepts
- proof-route seeding and evidence capture
- replay-history and analytics emphasis
- export-oriented maintainer tooling

## Why
The user redirected the product toward a learner-first experience for knowledge workers. v9 follows that instruction directly.
