# Product Requirements Document

## Core requirement
The application must help a learner complete a mission from launcher to debrief in roughly 5–10 minutes while practicing Chapter 4 reasoning.

## Required capabilities
- mission selection
- baseline vs candidate comparison
- standing-check review
- visible scoring and coaching
- release decision + monitoring follow-up
- debrief + strongest-practice walkthrough

## Explicitly removed in v9
- verification workspace
- proof-route seeding
- evidence tracking and export
- run persistence and migrations
- replay history and launcher analytics
- debrief export/download
