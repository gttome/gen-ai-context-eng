# Product Definition and Vision

Regression Watchtower is a short-session educational application for knowledge workers. Its purpose is to teach disciplined release judgment by comparing a candidate change against a trusted baseline, reviewing standing checks, choosing a release decision, and defining monitoring follow-up.

## v9 emphasis
The v9 package intentionally centers learning. It removes developer-oriented verification, replay-history, and export features that distracted from the core educational loop.
